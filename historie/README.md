# Jak opowiadać historie, które poruszają. Warsztat o tworzeniu historii z przesłaniem.

## Abstract
Dobra historia to nie informacja, nie liczba, to bohater, który ma cel, problem do rozwiązania i przechodzi przemianę.Najbardziej poruszają nas konkretne, przesiąknięte emocjami sceny i to one zapadają nam w pamięć. Budowanie historii może być proste. Rozbierzmy sobie cały proces na czynniki pierwsze i przećwiczmy wszystko w praktyce.

## Setup
Made using [Slidev](https://github.com/slidevjs/slidev)!

To start the slide show:

- `pnpm install`
- `pnpm dev`
- visit <http://localhost:3030>

Exporting:  
- add `pnpm add -D playwright-chromium`
- then `pnpm run export` by default exports pdf
- `pnpm run export --format pptx` exports pptx
